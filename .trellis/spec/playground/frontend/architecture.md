# Architecture

## Browser-Only SPA

`vite.config.ts` enables TanStack Start SPA mode because
`@figit/dom-to-figma` requires real browser APIs and layout. Do not move
converter imports into an SSR loader or re-enable route SSR without isolating
all DOM-dependent code and testing both execution paths.

## Directory Ownership

- `src/routes/` owns route declarations and route-level loading/not-found UI.
- `src/corpus/` owns raw HTML scene discovery and stable scene metadata.
- `src/components/playground-shell.tsx` owns the editor/preview/convert/copy
  workflow.
- `src/components/payload-inspector.tsx` owns read-only payload visualization.
- `src/lib/converter.ts` owns retained converter instances.
- `src/styles.css` imports shared UI tokens and declares Tailwind source paths.

Keep converter and corpus mechanics out of route components. Routes should
select data and compose the workbench.

## Dependencies

Use `@figit/dom-to-figma` through its public workspace API and shared controls
through explicit `@figit/ui` subpath exports. `src/styles.css` must continue to
scan `internal/ui/src` so Tailwind emits classes used inside shared components.

`src/routeTree.gen.ts` is generated by TanStack Router and excluded from normal
formatting. Never edit it by hand.
